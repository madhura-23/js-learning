## ⚡ Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/madhura-23/js-learning.git

# 2. Move into the folder
cd js-learning

# 3. Run any file with Node.js
node counter.js
node MEMOIZE.JS
node "Gas Station.js"
```

> **Prerequisite:** [Node.js](https://nodejs.org/) installed on your machine.

## 🔍 Highlight Snippets

**Memoization** — `MEMOIZE.JS`
Caching function results to avoid redundant computation — a core performance pattern in JavaScript.

**Function Composition** — `functioncomposition.js`
Chaining pure functions to build complex behavior from simple building blocks.

**Debounce** — `debounce.js`
Controlling how often a function fires — essential for search inputs and scroll events.

**Array Reduce** — `ArrayReduce.js`
The Swiss Army knife of array methods, explored in depth.
